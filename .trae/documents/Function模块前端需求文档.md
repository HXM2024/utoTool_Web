## 1. 产品定位与使用场景

**定位**：Function 模块用于「功能测试用例」的配置、编排与生成。使用者以图形化方式（工况画布）编排注入/序列/检查三类卡片，最终生成 CANoe 可直接使用的 CAPL 产物（`TestCase.can` / `TestFunction.cin` / `ArrayFuncTest.cin`）。

**典型使用路径**：
1. 选/建配置 → 填配置参数 → 编排用例分组 → 图形配置编排工况 → 保存 → 生成文件 → 在代码预览中核对。
2. 复用：把分组/卡片/映射/值资源「设为全局」，或在配置间复制/推送分组、导出导入分组文件。

**角色**：测试工程师（主要）、测试开发（维护函数库与映射表）。

### 3.8 工况画布（FR-CANVAS）

| 编号 | 需求 | 规则与约束 | 交互与反馈 | 验收标准 |
|---|---|---|---|---|
| FR-CANVAS-1 | 工况管理 | 新建工况（Insert）；工况标签切换（画布一次只挂载一个工况）；上一/下一工况；复制工况；删除工况 | 计数标签「N 个工况框」；上一/下一按边界禁用 | 新建后自动切到新工况；复制工况后两份内容互不影响 |
| FR-CANVAS-2 | 复制工况须换新 id | 深拷贝后 node/step/lane/edge id 全部重新生成，并重写端口键引用 | `cloneFrameWithNewIds` | 复制后修改任一工况不影响另一份 |
| FR-CANVAS-3 | 泳道 | 每个工况必须有且仅有一条「主序列」泳道；其它泳道可增删、左右移动、拖拽排序 | 泳道头显示名称/卡片数/左移右移/删除（主序列不可删） | 主序列泳道删除按钮不出现 |
| FR-CANVAS-4 | 泳道准入规则 | 主序列泳道只接受 `sequence` 类型卡片，且只放一张；其它泳道接受任意卡片 | 违规拖入时提示「主序列泳道只放「序列」卡片…」 | 把注入卡拖到主序列被拒绝并提示 |
| FR-CANVAS-5 | 卡片自动归侧 | 入口来源卡（卡片→主序列）自动归主序列左侧；出口目标卡（主序列→卡片）归右侧；链式卡跟随同侧邻居；无连线依据时尊重落点 | 自动改投时提示「已自动放到主序列左/右侧的泳道」 | 在右侧放一张注入卡后连到主序列，连线被判定为跨越并拒绝 |
| FR-CANVAS-6 | 连线方向合法性 | 仅允许：卡片→卡片（两端不同）、卡片→主序列、主序列→卡片 | 非法时提示「连线方向不合法（仅支持：卡片→卡片、卡片→主序列、主序列→卡片）」 | 主序列→主序列被拒绝 |
| FR-CANVAS-7 | 禁止跨越主序列 | 入口只能来自主序列左侧卡片、出口只能连到右侧卡片、两侧卡片不能互连 | 提示「连线不能跨越主序列…」；结构改动（拖卡片跨线/泳道换位）会导致新增跨越时整体拒绝并提示 | 上述三类操作均被拦下并给出原因 |
| FR-CANVAS-8 | 三种连线方式并存 | ①拖拽（输出口按下→输入口松开）②点击（单击口起虚线→再点另一口）③Ctrl 两步（Ctrl 点输出口→Ctrl 点输入口） | 三态光标/虚线跟随鼠标；Esc 或点空白取消 | 三种方式都能建立同一条连线 |
| FR-CANVAS-9 | 多选批量连线 | 已多选卡片（≥2）时 Ctrl 点接线口 = 把选中卡片批量连到该口 | 汇总提示「已创建 N 条连线，跳过 M 条…」 | 多选 3 张卡后 Ctrl 点输入口，生成 3 条连线（不合法的被跳过并计数） |
| FR-CANVAS-10 | 连线编号 | 序号锚定到步骤（`seq:<seqId>@<stepId>`）；支持继承/汇合；同名编号一起高亮 | 单击连线或编号徽标高亮（展开同编号）；双击线删除；双击徽标选编号（点选/Ctrl 多选/Shift 连选/拖拽框选，清空=全部，显示 All） | 重排主序列步骤后连线仍锚定原步骤 |
| FR-CANVAS-11 | 旧格式接线口自动升级 | 打开配置时把 `seq:<seqId>:<idx>` 升级为锚定格式 | 升级后提示「已把 N 个旧格式接线口升级为「锚定步骤」」 | 旧配置打开后连线仍能绘制 |
| FR-CANVAS-12 | 主序列步骤变化自动改锚 | 编辑主序列导致步骤增删时，被删步骤上的连线就近改锚到相邻存活步骤 | 提示「主序列步骤已变化，已自动调整 N 条连线的接线口」 | 删掉主序列中间一步后连线不断裂 |
| FR-CANVAS-13 | 选中与多选 | 单击选中卡片/泳道；Shift+点击=范围选（上次锚点→本次）；框选=框内卡片+连线 | 空白处点击清空选中；Esc（soft）清空选中 | 框选后 Delete 可批量删除 |
| FR-CANVAS-14 | 撤销/重做 | 快照式、上限 60 步，覆盖拖拽/增删/粘贴等全部画布改动 | `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`；按钮按栈空禁用；toast「已撤销/已重做」 | 连续 65 次改动后仍可撤销最近 60 步 |
| FR-CANVAS-15 | 复制/粘贴 | `Ctrl+C`/`Ctrl+V`；粘贴落点为「最近点击或划过的泳道」，无落点时报错提示；主序列粘贴=替换原序列 | 提示「已复制 N 张卡片 / 已粘贴 N 张卡片」 | 复制一张卡后点目标泳道再 Ctrl+V 成功粘贴 |
| FR-CANVAS-16 | Ctrl+拖拽复制 | 卡片/泳道 Ctrl 拖拽=复制（原件保留） | 落点插入到目标位置 | 拖动时出现复制光标且原件不动 |
| FR-CANVAS-17 | 删除卡片 | 卡片 ✕ 按钮；或拖出工况框（不落在任何泳道/卡片上）删除 | 删除后可 Ctrl+Z 撤销 | 误删可从撤销恢复 |
| FR-CANVAS-18 | 删除泳道 | 二次确认，文案含「将同时删除该泳道内 N 张卡片及相关 M 条连线」 | 删除后 toast + 可撤销 | 取消则不删 |

| 编号 | 需求 | 规则与约束 | 验收标准 |

| FR-DATA-4 | 工况结构 | `{id,name,lanes[{id,type,nodeIds,width}],nodes{},edges{}[,caseNames]}`；泳道类型仅 `main/other` | 一个工况最多一条 `main` 泳道 |

| FR-DATA-9 | 全局库契约 | GET/POST `/function/global-library`，字段 `function_library / step_library / inject_library / result_library / cards / mapping / value_library` | 保存后 GET 能取回同值 |

## 6. 术语表

| 术语 | 含义 |
|---|---|
| 工况（frame） | 一个用例模板；含泳道、卡片、连线；展开后成为若干条用例 |
| 主序列 | 每个工况的用例主干，是一条特殊泳道（`type=main`），只放 `sequence` 卡片 |
| 卡片（Card） | 可复用的操作单元，类型为注入/序列/结果；含步骤序列与参数接口 |
| 步骤（CardStep） | 卡片内的一条操作（函数调用、设置、检查、循环…），`kind` 共 14 种 |
| 参数（接口） | 卡片声明的占位符（`{{名}}`），引用本卡片时可分别填值 |
| 引用卡片 | 卡片 A 的某个步骤引用卡片 B（`kind='card'`），A 可给 B 的参数填值 |
| 接线口 / 端口 | 卡片与主序列上用于连线的锚点；key 约定见 FR-DATA-5 |
| 用例编号 | 连线上的序号，决定用例路径的分支；锚定到主序列步骤 id |
| 全局标记 | 卡片/映射/值资源上的 `global:true`，新建分组时自动带出 |
| 值资源 | 常量/列表/区间，用 `@const:/@list:/@range:` 在参数框引用 |
| 映射变量 | `变量名 ↔ 对象` 的对照，步骤里用变量名书写、生成时替换为对象 |

## 8. 后续使用建议

1. **作为验收基线**：第 3 章每条 FR 的「验收标准」可直接转成测试用例；第 5 章「未实现/待明确」是当前已知缺口，可作为下一轮迭代的输入。
2. **作为实现依据**：任何新改动都应先判定是否触碰第 3.16 的契约（FR-DATA-9~12）；契约变更需前后端同步并更新本文档。
3. **口径统一**：第 5 章中「两入口行为不一致」（FR-CARD-2、FR-CARD-14 等）若决定统一，需先更新本文档再改代码。
4. **回归重点**：FR-CANVAS-2（复制工况换 id）、FR-DATA-5（端口键）、FR-DATA-6（分组隔离）三处是历史上出过问题的区域，改动画布/分组时必须回归。
