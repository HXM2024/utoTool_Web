# Function 模块：多选连线右键批量改编号

## Summary

在 Function 模块的工况画布中，连线已支持 Ctrl/Shift 单击、拖拽框选多选。本次新增：**显式多选 ≥2 条连线后，右击其中任意一条连线的编号徽标（或连线本体），打开编号面板，把一组编号统一写入所有选中连线**。

已与用户确认的两条决策：

* 批量语义 = **所有选中连线统一写入同一组编号**（不是顺序递增、也不是逐条偏移）。

* 触发范围 = **仅多选（≥2 条显式选中）时**改成批量改号；只选 1 条时右击仍保持现有「预览该编号用例代码」。

不改动后端：编号字段 `seq` / `pair` 已是前后端共享约定，后端 `_resolve_frame_numbers` 已按同一规则解析。

### 2. 新增打开批量面板的函数

```ts
/** 多选状态下右击某条选中连线：把「当前显式选中且同工况存在」的连线作为批量目标 */
function openBatchEdgeNum(frameId: string, edgeId: string) {
  const f = frames.value.find((x) => x.id === frameId)
  if (!f || !f.edges[edgeId]) return
  const ids = selectedEdgeIds.value.filter((id) => !!f.edges[id])
  if (ids.length < 2) return
  editingEdgeId.value = edgeId              // 面板挂在这条徽标上
  editingEdgeFrameId.value = frameId
  batchEdgeIds.value = ids
  const eff = (edgePathCache.value[frameId] || []).find((p) => p.edgeId === edgeId)?.nums ?? storedEdgeNums(f.edges[edgeId])
  edgeSeedNums = [...eff]
  editingEdgeValue.value = eff.join(',')    // 回填锚点线的生效编号；不改就直接关闭
  numAnchorIdx = null
}
```

### 4. 候选编号与状态展示适配批量

* `numCandidates(frameId, edgeId)`（L3889-L3896）改为：候选 = 本工况 `frameCaseNums` ∪ **所有批量目标线的存储编号**（单条时批量为空，行为不变）：

```ts
function numCandidates(frameId: string, edgeId: string): number[] {
  const f = frames.value.find((x) => x.id === frameId)
  if (!f) return []
  const set = new Set<number>(frameCaseNums.value[frameId] || [])
  const ids = batchEdgeIds.value.length ? batchEdgeIds.value : [edgeId]
  for (const id of ids) {
    const e = f.edges[id]
    if (e) for (const n of storedEdgeNums(e)) set.add(n)
  }
  return Array.from(set).sort((a, b) => a - b)
}
```

### 5. 提交：统一写入同组编号（一次撤销）

改造 `saveEdgeInline()`（L4065-L4083）：目标集合 = `batchEdgeIds` 非空则用它，否则 `[editingEdgeId]`；编号串未变化则直接关闭（沿用 `edgeSeedNums` 守卫）；有变化时逐条按现有单条规则写入，最后只 `emitChange()` 一次：

```ts
function saveEdgeInline() {
  const f = frames.value.find((x) => x.id === editingEdgeFrameId.value)
  const nums = parseEdgeNums(editingEdgeValue.value.trim())
  const changed = nums.join(',') !== edgeSeedNums.join(',')
  const ids = batchEdgeIds.value.length ? [...batchEdgeIds.value] : [editingEdgeId.value]
  if (f && changed) {
    let n = 0
    for (const id of ids) {
      const e = f.edges[id]
      if (!e) continue
      if (edgeKind(e) === 'entry') {
        e.seq = nums.length ? nums[0] : 0
        e.pair = nums.length > 1 ? nums : []
      } else {
        e.pair = nums
      }
      n++
    }
    if (n) emitChange()
    if (n > 1) ElMessage.success(`已批量更新 ${n} 条连线的编号`)
  }
  cancelEdgeEdit()
  scheduleRecompute()
}
```

要点：

* entry（注入线）写 `seq + pair`，exit/chain 写 `pair`，与单条编辑完全一致，兼容旧数据与后端解析。

* 空串批量 = 各线回到自动排号 / 全部（与现有单条「清空」语义一致）。

* 只调用一次 `emitChange()`，Ctrl+Z 一次撤销整批。

* 批量目标不足 2 条（例如过程中线被删）时按剩余条数处理；全部失效则只关闭面板。

## Assumptions & Decisions

1. 批量范围 = `selectedEdgeIds`（显式 Ctrl/Shift/框选），不是 `isEdgeHighlighted` 的同编号扩展。
2. 右击的连线必须已在选中集合里，且选中数 ≥2，才进入批量；否则退回单条右键行为。
3. 单条右击仍是「预览用例代码」；双击仍是单条编号编辑；两者均不改变。
4. 批量写入的编号对注入线 / 结果线 / 链式线采用各自现有存储规则，不做类型过滤，也不提示混选。
5. 面板锚点 = 右击的那条连线的编号徽标；该线在选中集合里，徽标一定可见（`badgeOnSelect` 也因选中而显示）。
6. 编号面板打开期间若用户点击面板外区域，现有 `onWindowMouseDown` 先自动保存并关闭，批量状态随之清空，不会残留。
